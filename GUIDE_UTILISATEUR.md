## 1. Configuration & IA

Studeo n'est pas une simple application, c'est une interface vers les meilleurs modèles d'IA du monde.

### 🤖 Choisir son Fournisseur d'IA

Rendez-vous dans les **Paramètres** (icône ⚙️) :

- **Google Gemini** ⭐ : Recommandé pour sa rapidité et sa gratuité (via clé API gratuite). Excellent pour le multimodal (images, PDF).
- **OpenAI (GPT-4o)** : Le standard de l'industrie, excellent pour les sujets complexes et la génération de contenu structuré.
- **Anthropic (Claude 3.5)** : Très nuancé, idéal pour l'écriture, les langues et les analyses approfondies.
- **Mistral AI** : Alternative européenne performante, bon équilibre qualité/prix.
- **IA Locale (Ollama/LM Studio)** : 100% privé, fonctionne sans internet si vous avez installé un serveur local.

### 🎙️ Moteurs de Voix (TTS)

Vous pouvez choisir la voix qui lit vos cartes :

- **Voix Système** : Utilise les voix installées sur votre ordinateur (macOS/Windows)
- **Voix Locale** : Pour une utilisation hors ligne
- Dans chaque écran d'étude, une icône de haut-parleur vous permet de tester et changer de voix

## 3. Génération de Contenu par IA

Studeo offre **plusieurs vecteurs de génération** pour créer du contenu pédagogique.

### 📝 **Sujet Manuel**

Tapez simplement ce que vous voulez apprendre :

- "Les verbes irréguliers en anglais"
- "La photosynthèse"
- "Accords de guitare pour débutants"

### 📄 **Depuis un Fichier Texte**

Importez vos cours existants :

- Formats supportés : `.txt`, `.md`
- L'IA analyse le contenu et génère automatiquement :
  - Des fiches de révision
  - Des questions de compréhension
  - Des points clés à retenir

### 🖼️ **Depuis un PDF/Image**

**Multimodal IA Vision** (Tous les fournisseurs) :

- Uploadez un PDF de cours, une page de manuel, un schéma
- L'IA "lit" le document et en extrait :
  - Les concepts principaux
  - Les définitions
  - Les formules et exemples
- Formats supportés : `.pdf`, `.jpg`, `.png`, `.webp`

### 🎤 **Depuis un Média Audio/Vidéo**

**Analyse multimédia** (Tous les fournisseurs) :

- Uploadez un cours enregistré, une conférence, un podcast
- L'IA transcrit et analyse :
  - Les points clés abordés
  - Les exemples donnés
  - Les concepts expliqués
- Formats supportés : `.mp3`, `.wav`, `.mp4`, `.webm`

### 🎨 **Types de Contenu Généré**

#### **Quiz (Fiches)**

- Flashcards classiques (recto/verso)
- QCM avec distracteurs intelligents
- Textes à trous (Cloze)
- Questions ouvertes

#### **Quiz Mixte**

Combine tous les types de questions pour une révision complète

#### **Cours (Leçons)**

- Contenu structuré en Markdown
- Explications détaillées
- Exemples concrets
- Exercices d'application
- Possibilité de générer un quiz de révision depuis le cours

#### **Programmes d'Étude**

- Parcours d'apprentissage complet
- Modules progressifs
- Objectifs pédagogiques clairs
- Évaluations intégrées
- Suivi de progression

## 6. Algorithme de Révision (SRS)

Studeo utilise la **Répétition Espacée** (Spaced Repetition System).

### 🧠 Principe

Plus vous trouvez une carte facile, plus elle réapparaîtra tard :

- **Difficile** : Revue dans 1 jour
- **Moyen** : Revue dans 3 jours
- **Facile** : Revue dans 7 jours (puis 15, 30, 60...)

### 📊 Suivi

- **Cartes dues** : Nombre de cartes à réviser aujourd'hui
- **En apprentissage** : Cartes en cours de mémorisation
- **Maîtrisées** : Cartes bien ancrées (intervalle > 21 jours)

### 💡 Conseils

- Soyez **honnête** avec l'algorithme
- Révisez **quotidiennement** pour de meilleurs résultats
- Les cartes difficiles reviendront plus souvent automatiquement

## 9. Sauvegarde & Synchronisation Cloud

### ☁️ Synchronisation Cloud (Nouveau) ✨

Studeo propose désormais une synchronisation automatique via **Supabase**. Cela vous permet de retrouver vos parcours, vos fiches et votre progression sur tous vos appareils (Mac, iPhone, iPad, Web).

1. **Activation** : Cliquez sur l'icône **Nuage** en haut à droite de l'écran d'accueil.
2. **Inscription** : Créez un compte avec votre email. Un email de confirmation vous sera envoyé.
3. **Automatique** : Une fois connecté (nuage vert), Studeo synchronise chaque modification en temps réel.
4. **Multi-appareils** : Connectez-vous avec le même compte sur un autre appareil pour récupérer instantanément vos données.

### 🔒 Confidentialité

- **Données Cloud** : Vos données sont stockées dans un espace privé et sécurisé. Seul votre identifiant peut y accéder.
- **Hors ligne** : L'application continue de fonctionner sans internet. Les changements seront synchronisés dès que la connexion reviendra.
- **Clés API** : Vos clés API (Gemini, OpenAI) restent stockées localement sur votre appareil pour une sécurité maximale.

### 💾 Backup Manuel

Même avec le Cloud, vous pouvez effectuer des sauvegardes manuelles dans les paramètres :

1. **"Exporter mes données"** : Génère un fichier `.json` complet de votre base locale.
2. **"Importer"** : Restaure une sauvegarde précédente ou fusionne des données.

## ❓ FAQ & Dépannage

### L'IA ne répond pas ?

- Vérifiez votre **clé API** dans les paramètres
- Assurez-vous d'avoir une **connexion internet** (sauf IA locale)
- Essayez de **changer de modèle**

### Les cartes ne se sauvegardent pas ?

- Vérifiez l'espace de stockage de votre navigateur
- Exportez vos données régulièrement
- En mode Tauri, vérifiez les permissions de l'application

### La reconnaissance vocale ne fonctionne pas ?

- Autorisez l'accès au **microphone** dans les paramètres système
- Vérifiez que votre navigateur supporte la Web Speech API
- Essayez de **parler plus fort** et plus clairement
